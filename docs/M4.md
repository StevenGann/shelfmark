# M4 — Substitutions

A BOM line names one part. Reality offers three that would do, one of which is
in the drawer. Substitution is a first-class fact about parts, not a note, and
it is what turns "40 short" into "40 short, but SK-00012 is the same 2.2 µF 0402
and there are 200 in Bin 12".

## Definition of done

1. A part can be linked to any number of substitutes, each with a fit level and
   a note, in one direction: *this may be used where that is called for*.
2. The part page lists substitutes in both directions and adding one takes an
   IPN or an MPN.
3. A BOM revision shows, for every line that is short, the substitutes that
   would cover it, with their stock and package.
4. A substitution never rewrites a BOM line. It is a suggestion until a human
   chooses it.
5. Links can be removed as easily as added, and the interface says who added
   one.

## Fit levels

Four words, each making a smaller claim than the one above it:

- **exact** — the same component under a second internal part number, typically a
  different packaging or a second supplier SKU. Nothing to think about.
- **equivalent** — same specifications from a different manufacturer.
- **form-fit** — same land pattern and the same function, with a stated
  difference: a different dielectric, a wider tolerance, a lower voltage rating.
  The note is required, because this is where judgement lives.
- **function** — works electrically but does not match the footprint, so it
  needs wire, an adapter or a re-spin.

The package of both parts is shown wherever a link is displayed. A `form-fit`
whose two packages differ is a mistake the interface should make obvious, not a
warning the database swallows.

## Schema

```sql
CREATE TABLE part_substitute (
  id INTEGER PRIMARY KEY,
  part_id INTEGER NOT NULL REFERENCES part(id) ON DELETE CASCADE,
  substitute_part_id INTEGER NOT NULL REFERENCES part(id) ON DELETE CASCADE,
  fit TEXT NOT NULL CHECK (fit IN ('exact','equivalent','form-fit','function')),
  note TEXT,
  created_by TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now')),
  UNIQUE (part_id, substitute_part_id),
  CHECK (part_id <> substitute_part_id),
  CHECK (fit <> 'form-fit' OR (note IS NOT NULL AND length(trim(note)) > 0))
);
```

Parts also gain a value, because "same 0402 2.2 µF" is the substitution people
actually make and the catalogue cannot say it today:

```sql
ALTER TABLE part ADD COLUMN value TEXT;
ALTER TABLE part ADD COLUMN value_norm TEXT;
CREATE INDEX part_value_norm ON part(value_norm);
```

`value_norm` folds case, spaces and the micro sign, so `2.2uF`, `2.2 µF` and
`2.2UF` are one value. BOM ingest fills both from the line when the part has no
value yet, and never overwrites a value an engineer typed.

`part_id` is the part a design calls for; `substitute_part_id` is what may be
used instead. The reverse is a separate row, because "a 10 k 1 % will do for a
10 k 5 %" does not imply the opposite.

## Surplus and shortfall

For a BOM line, the useful numbers are:

- `required` — the line quantity;
- `on_hand` — stock for the part the line matches;
- `short` — `max(0, required - on_hand)`;
- for each substitute: its `on_hand` and whether it covers `short`.

`repo/offers` already answers price; this milestone only needs stock, so a
line's suggestion list is ordered by: exact, equivalent, form-fit, function,
and within a fit level by how much stock is available.

## API

| method | path | notes |
|--------|------|-------|
| `GET` | `/api/parts/{ipn}/substitutes` | links out, with each substitute's stock and package; `?direction=in` lists who can stand in for this part |
| `POST` | `/api/parts/{ipn}/substitutes` | `{substitute: "<ipn or mpn>", fit, note}`; 404 unknown part, 409 existing link, 422 self-link |
| `DELETE` | `/api/parts/{ipn}/substitutes/{substitute_ipn}` | removes one link |
| `GET` | `/api/parts/{ipn}/substitute-suggestions` | parts not yet linked that share `package` and `value_norm`, for the "same 0402 2.2 µF" case |

Reads viewer, writes engineer.

## CLI

```
shelfmark subs list SK-00001
shelfmark subs add SK-00001 SK-00012 --fit equivalent --note "same 2.2uF 10V X7R"
shelfmark subs remove SK-00001 SK-00012
```

## Interface

On the part page, a **Substitutes** panel: a table of substitutes with IPN, MPN,
package, fit, stock and note; a remove control per row; and an add form taking
an IPN or MPN, a fit selector, and a note that becomes required when
`form-fit` is chosen.

On a revision page, each line that is short shows its substitutes inline:
"short 40 — SK-00012 equivalent, 200 on hand". A line that is fully covered
says nothing.

## Tests

- a link round-trips through the API and appears in both directions
- linking a part to itself is refused
- a duplicate link is refused
- `form-fit` without a note is refused; with a note it is accepted
- removing a link changes both lists
- shortfall arithmetic: required 20, on hand 12, substitute on hand 15 → short 8
- suggestions exclude parts already linked, and require both package and value to match
- a value typed as `2.2uF` matches one stored as `2.2 µF`
- viewer gets 403 on writes
